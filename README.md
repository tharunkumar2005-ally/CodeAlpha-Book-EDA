# CodeAlpha Book Exploratory Data Analysis

An exploratory data analysis project for a small book catalog, created as part of the CodeAlpha Data Analytics Internship. The project cleans and summarizes the dataset, examines book prices, ratings, and availability, and produces visualizations and a text report.

## Project Overview

This project uses Python to explore a book dataset and present its key patterns in a clear, reproducible way. The analysis script reads the source CSV, standardizes and cleans the data, calculates descriptive statistics, creates five charts, and saves an EDA report.

## Project Objectives

- Inspect the dataset's structure, data types, missing values, and duplicate records.
- Prepare price, rating, and availability fields for analysis.
- Summarize prices, ratings, and stock availability.
- Explore the relationship between book price and rating.
- Communicate the results through charts and a concise report.

## Technologies Used

- **Python** – analysis workflow and scripting
- **Pandas** – data loading, cleaning, and analysis
- **NumPy** – numerical computing used with the Python data-analysis stack
- **Matplotlib** – chart creation
- **Seaborn** – statistical visualizations

## Dataset Description

The source file, `books_dataset.csv`, contains 12 book records and these six columns:

| Column | Description |
| --- | --- |
| `title` | Book title |
| `author` | Book author |
| `price` | Book price |
| `rating` | Book rating |
| `availability` | Stock status |
| `genre` | Book genre |

The script looks for the source CSV in the project root or in the `data/` folder. It saves the cleaned dataset to `data/cleaned_books_dataset.csv`.

## Exploratory Data Analysis

The analysis includes:

- Dataset dimensions, column types, missing-value checks, and duplicate checks.
- Descriptive statistics for numeric columns, including price and rating.
- Minimum and maximum book prices, rating summaries, and availability counts.
- Pearson correlation and average ratings across price quartiles.
- Visual summaries of price distribution, rating counts, availability, price versus rating, and numeric correlations.

## Key Findings

Based on the current EDA report:

- **Records analyzed:** 12
- **Source columns:** 6
- **Missing values:** 0
- **Duplicate records:** 0
- **Average book price:** 381.42
- **Average rating:** 4.60
- **Availability:** 8 in stock, 3 low stock, and 1 out of stock
- **Price-rating correlation:** 0.653, a positive association in this sample

The dataset is small, so the observed price-rating relationship is exploratory and should not be interpreted as causal or generalized to a broader catalog.

## Requirements

Use Python 3.9 or newer.

## Setup

1. Open the project folder in VS Code.
2. Create and activate a virtual environment (recommended):

   ```bash
   python -m venv .venv
   .venv\Scripts\activate
   ```

3. Install the required packages:

   ```bash
   pip install -r requirements.txt
   ```

4. Place your `books_dataset.csv` file in either:
   - the project root, or
   - the `data/` folder.

## How to Run the Project

From the project directory, run:

```bash
python eda.py
```

The script prints the analysis summary and saves the cleaned dataset, five charts, and EDA report to the existing `data/` and `output/` folders.

## Project Structure

- `eda.py` – data cleaning, analysis, chart generation, and report creation.
- `books_dataset.csv` – source dataset (also supported in `data/`).
- `data/cleaned_books_dataset.csv` – cleaned dataset generated by the script.
- `output/` – generated charts and `eda_report.txt`.
- `requirements.txt` – Python dependencies.

## Project Conclusion

This project demonstrates an end-to-end EDA workflow, from checking and preparing a dataset to summarizing findings with visualizations. The catalog has no missing or duplicate records, an average rating of 4.60, and a positive price-rating association in this 12-book sample. The report and charts provide a clear snapshot of this dataset while recognizing that a larger sample would be needed for broader conclusions.
